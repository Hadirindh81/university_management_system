

 Imperial University Management System

A modern, efficient, and user-friendly web-based application built with Django for managing all academic operations — including students, teachers, courses, and fees — within a single platform.

# Features

Smart Dashboards:
Separate dashboards for Admin, Teacher, and Student — each designed for clarity and ease of use.

 Student Management
Add, edit, and track student records including personal details and enrolled courses.

Teacher Management
Manage teachers, assignments, and courses taught by each faculty member.

Course Management
Add, update, and delete courses with department-level categorization.

Fee Management
Track and record student fee submissions and due balances.

User Authentication System
Secure login & registration for all users (Admin / Teacher / Student).

Reports & Insights
Visual reports and progress data to support decision-making.

Modern Responsive UI
Clean interface using Bootstrap 5 — professional look on desktop and mobile.

# How to Run the Project Locally

1. Clone this repository

   ```bash
   git clone https://github.com/Hadirindh81/university_management_system.git
   ```

2. Navigate into the project folder

   ```bash
   cd university_management_system/Home
   ```

3. Create and activate a virtual environment (recommended)

   ```bash
   python -m venv venv
   venv\Scripts\activate      # On Windows
   ```

4. Install dependencies

   ```bash
   pip install django
   ```

5. Run the development server

   ```bash
   python manage.py runserver
   ```

6. Open in browser

   ```
   http://127.0.0.1:8000/
   ```
